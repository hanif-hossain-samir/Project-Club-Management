# City University Events & Clubs (CUEC)

Official portal for **City University Computer Club (CUCC)** wing approvals, events & competitions, circular notices, gallery photo curation, and controller command operations.

## Stack
- **Frontend**: HTML5, CSS3, CSS Modules (`*.module.css`), JavaScript, React
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose ODM with automatic seeded fallback when `mongod` is offline)

## Commands
- `npm run dev` — Start Express + Vite dev server on port `3000`
- `npm run build` — Build frontend bundle into `dist/`
- `npm start` — Run production Express server on port `3000`
- `npm run lint` — Verify JavaScript syntax checks and execute Node test suites (`tests/*.test.js`)
